# Jobs de Entrenamiento - AMD y NVIDIA

Este directorio contiene los jobs utilizados para la ejecución y entrenamiento de modelos de Deep Learning en arquitecturas GPU de AMD y NVIDIA.

## Modelos Incluidos

### Perceptrón Multicapa (MLP)
Se incluyen configuraciones y jobs para los siguientes modelos:

- MLP-3
- MLP-5
- MLP-7

Cada variante representa una arquitectura con diferente número de capas ocultas.

---

### Redes Neuronales Convolucionales (CNN)
Se incluyen jobs para las siguientes arquitecturas convolucionales:

- LeNet-5
- AlexNet
- VGG-16

Estas arquitecturas fueron utilizadas para evaluar desempeño, consumo de recursos y comportamiento computacional en diferentes entornos GPU.

---

## Contenido del Directorio

Los archivos presentes pueden incluir:

- Scripts de ejecución (.sh)
- Configuraciones de entrenamiento
- Configuraciones específicas para GPU AMD y NVIDIA
